# MarketMint — Luxury 3D Marketplace Universe

MarketMint is a fully responsive, multi-page futuristic marketplace experience built with plain HTML5, CSS3 and JavaScript.

## Included
- 3D cinematic background environment with globe, rings, cubes, spheres, diamonds and particles
- Mouse parallax, floating animation, depth layers and glassmorphism
- Home, Marketplace, Login, Signup, About, Seller Dashboard and Buyer Dashboard
- Product search, category filtering, sorting, wishlist and cart interactions via localStorage
- Product details modal
- Responsive desktop/tablet/mobile layouts
- No Bootstrap or UI template dependencies
- Generated luxury universe background image in `assets/marketmint-universe.png`

## Run
Open `index.html` directly in a browser, or serve the folder with any static server.

For example:

```bash
npx serve .
```

The project is front-end only. Authentication, payment, inventory and live analytics are intentionally represented with demo interactions and are ready to be connected to a backend/API.
